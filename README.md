# news-blocklist
A simple blocklist for all websites revolving around politics and the daily news cycle. Because we should all [stop reading the news](https://www.amazon.com/Stop-Reading-News-Manifesto-Happier-ebook/dp/B07SD5TPP1).

This is not a hosts file. I recommend you use this blocklist with [Blocky](https://0xerr0r.github.io/blocky/latest/).

*Blocked:*
- Most popular news websites
- X/Twitter and popular Nitter instances
- Thinktanks
- Pollsters
- Hacker News
- Bing (because they don't use a news subdomain)
- Bitchute 
- Gab
- Lemmy
- Truth Social
- Polymarket

*Not blocked:*
- Reddit
- YouTube
- Non-political news (sports, technology, etc). I may make a separate category for that later.

Missing something? Feel free to submit a pull request.
